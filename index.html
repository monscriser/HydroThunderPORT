PC port features

A Vulkan-powered experimental port with flexible controls and setup.

🖥️ Windows & Linux

Native Windows executable with separate launcher; Linux AppImage with integrated launcher.

🎮 Input & local play

Controllers, remappable keyboard keys and experimental local split-screen configurations.

🌊 Vulkan graphics

FSR 1 scaling, experimental FSR 3.1 reconstruction, optional FXAA and display settings.

⚡ Performance controls

Shader/pipeline caching, FPS limits and configurable engine optimizations.

🧰 Guided launcher

Set up your own game, DLC and update files, adjust settings and manage save backups.

🕹️ Handheld testing

ROG Ally, CachyOS and Steam Deck are targeted, with more hardware validation required.

How to get started

  1. Download the Windows or Linux package from the official GitHub Releases.
  2. On Windows, open Launcher-Config.exe. On Linux, grant execution permission to the AppImage and open it.
  3. Select your legally obtained game files and any supported updates/DLC.
  4. Configure video and controls, then start the game.
