## 2. O que é o projeto
Port nativo do Hydro Thunder Hurricane (Xbox 360 XBLA, título 5841096A, update 0.0.2.1), feito por recompilação estática com o **ReXGlue SDK**, um derivado do Xenia com backend Vulkan.
- `app/`: código do app (launcher, overlay, tradução, Steam). `app/generated-updated/`: código recompilado do jogo.
- SDK = rexglue-sdk na revisão de `provenance.json` + `rexglue-modifications.patch` + arquivos de `sdk-extra/`.
- `translations/`: textos pt-BR. `steam_art/`: artes da Steam. `tools/`: scripts de build, teste e tradução.

## 5. Como compilar (WSL)
Rode sempre **scripts em arquivo**, convertendo CRLF: `wsl.exe -d Ubuntu-24.04 -u root -- bash -c "tr -d '\r' < <script.sh> > /root/x.sh && bash /root/x.sh ..."`.
- Primeira vez num WSL limpo: `tools/wsl/setup.sh <fontes>` e depois `tools/wsl/build.sh win` / `build.sh linux`.
- Depois de mudar o código: copiar os arquivos alterados de `app/` para `/root/ht/src/app/` e rodar `tools/wsl/rebuild_win.sh 15 win` (ou `... 15 linux`). As saídas ficam em `/root/ht/build-win/` (`hydrothunder.exe`, `librexruntime.dll`, `rexgpu-xenos.dll`, `libamd_fidelityfx_vk.dll`).
- Mudanças no SDK ficam em `/root/ht/sdk`. Depois de mudar: `tools/wsl/regen_patch.sh <fontes> /root/new.patch` e copiar para `rexglue-modifications.patch`.
- Shaders RCAS: `tools/shaders/build_rcas_guard.sh [baixo] [alto]`.
- Empacotar: `tools/pkg_toml.py` (padrões do toml), `tools/make_zip.py` (zip com `/`), `tools/wsl/package_linux.sh`, `tools/wsl/check_ffx_pkgs.sh`, `tools/check_sources_zip.py`. Depois gerar o SHA256.

**Armadilhas já encontradas:**
- O Git Bash converte caminhos `/...` e `$VAR`; isso já **quebrou o `/bin` do WSL** (conserto: `wsl.exe -u root -e /usr/bin/ln -sfn usr/bin /bin`). Use PowerShell + scripts em arquivo.
- O PowerShell 5.1 também interpreta `$(...)` e `\$` dentro de aspas duplas: prefira scripts.
- O `Compress-Archive` do PS 5.1 grava `\` nos zips: use `tools/make_zip.py`.
- Não matar processos filtrando por um texto que esteja na própria linha de comando (o comando acaba matando a si mesmo).
